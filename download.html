下载后怎么用

            
给完全不熟 GitHub 的用户看的最短路径。

          

        

        

          

            
Windows

            
    
              
  • 下载 Setup 安装包 并双击安装。
    • 
              
  • 若只有 zip，解压后运行里面的启动脚本 / `lh.exe`。
    • 
              
  • 安装后可在终端执行 `lh init`，再 `lh tui` 或打开 Desktop。
    • 
            

          

          

            
macOS

            
    
              
  • 优先下载对应芯片的 .pkg 安装。
    • 
              
  • Apple Silicon 选 `arm64`，Intel 选 `amd64`。
    • 
              
  • 若系统拦截，可在“隐私与安全性”里允许打开。
    • 
            

          

          

            
Linux / Android

            
    
              
  • Debian/Ubuntu 优先用 `.deb`；其他发行版可用 `.tar.gz`。
    • 
              
  • Android 下载 APK 后允许“未知来源”安装。
    • 
              
  • 更完整的部署说明见知识库里的 Install / Runtime 章节。
