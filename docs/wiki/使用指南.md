# 使用指南

这页介绍 LuckyAgent 从初始化到启动各类入口的基本流程。

## 环境要求

- Go 环境，项目当前通过 `go run ./cmd/la ...` 直接运行。
- 可用的 OpenAI-compatible 模型服务，或其他已配置 provider。
- 如需 GUI/TUI 前端开发，需要 Node.js 和 npm。
- 如需 Docker 部署，需要 Docker 和 Docker Compose。

## 1. 初始化运行目录

LuckyAgent 默认读取：

```text
${HOME}/.luckyagent/config.json
```

先执行初始化：

```bash
go run ./cmd/la init
```

初始化后会生成类似结构：

```text
~/.luckyagent/
├── config.json
├── SOUL.md
├── sessions/
├── memory/
├── logs/
├── skills/
├── rag/
├── workspace/
├── runtime/
└── data/
```

## 2. 配置模型

最小配置通常包括 provider、API key、API base 和模型名。

```bash
go run ./cmd/la config set provider openai
go run ./cmd/la config set api_key sk-your-api-key
go run ./cmd/la config set api_base https://api.openai.com/v1
go run ./cmd/la config set model gpt-5.4-mini
```

查看配置：

```bash
go run ./cmd/la config list
go run ./cmd/la config get model
```

自动引用尾注默认关闭。如需在回答末尾显示工具来源引用，可以开启：

```bash
go run ./cmd/la config set agent.enable_citations true
```

关闭自动引用：

```bash
go run ./cmd/la config set agent.enable_citations false
```

## 3. 本地聊天调试

单轮调用：

```bash
go run ./cmd/la chat "Summarize this repository"
```

进入 REPL：

```bash
go run ./cmd/la chat
```

适合用来调试 prompt、工具调用、RAG、记忆和模型配置。

## 4. 启动 HTTP API

```bash
go run ./cmd/la serve --addr 127.0.0.1:9090
```

健康检查：

```bash
curl http://127.0.0.1:9090/api/v1/health
```

如果要让容器或其他机器访问，配置里的 `server.addr` 通常需要设为：

```text
0.0.0.0:9090
```

## 5. 启动 GUI Dashboard

Dashboard 适合观察运行状态、会话和活动流。

源码方式通常先启动 API：

```bash
go run ./cmd/la serve --addr 127.0.0.1:9090
```

前端开发模式：

```bash
cd UI
npm install
npm run dev --workspace GUI
```

构建 GUI：

```bash
cd UI
npm run build --workspace GUI
```

Go dashboard 会在存在 `UI/GUI/dist` 时优先服务该目录。

## 6. 启动 TUI

TUI 适合在终端里长期对话、切换会话和执行常用命令。

```bash
cd UI
npm run dev --workspace TUI -- --api-base http://127.0.0.1:9090 --session dashboard-main
```

或使用项目 Makefile：

```bash
make tui
```

## 7. 启动消息网关

### Telegram

配置：

```bash
go run ./cmd/la config set msg_gateway.telegram.token your-telegram-bot-token
```

启动：

```bash
go run ./cmd/la msg-gateway start --platform telegram
```

### QQ 官方机器人

关键字段：

- `msg_gateway.qqofficial.app_id`
- `msg_gateway.qqofficial.app_secret`
- `msg_gateway.qqofficial.proxy`（可选；支持 `http`、`https`、`socks5`、`socks5h`）
- `msg_gateway.qqofficial.sandbox`
- `msg_gateway.qqofficial.allowed_chats`
- `msg_gateway.qqofficial.allowed_users`

启动：

```bash
go run ./cmd/la msg-gateway start --platform qqofficial
```

`proxy` 留空时网关直连，不读取代理环境变量；启动和重连错误会写入 `${HOME}/.luckyagent/logs/qqofficial-gateway.log`。

### NapCat / OneBot v11

LuckyAgent 作为反向 WebSocket 服务端，NapCat 主动连接进来。

```bash
go run ./cmd/la config set msg_gateway.napcat.listen_addr 127.0.0.1:6701
go run ./cmd/la config set msg_gateway.napcat.path /onebot/v11/ws
go run ./cmd/la msg-gateway start --platform napcat
```

跨机器部署时，监听地址通常要改成：

```bash
go run ./cmd/la config set msg_gateway.napcat.listen_addr 0.0.0.0:6701
```

### 飞书

至少配置应用凭证：

```bash
go run ./cmd/la config set msg_gateway.feishu.app_id cli_xxx
go run ./cmd/la config set msg_gateway.feishu.app_secret your-app-secret
go run ./cmd/la msg-gateway start --platform feishu
```

默认使用飞书长连接接收事件，不要求 LuckyAgent 暴露回调地址。若改用 HTTP 回调，配置 `verification_token`，并在飞书开放平台订阅 `im.message.receive_v1`、填写配置中的 `listen_addr` 和 `path`。启用事件加密时还要配置 `encrypt_key`；回调模式要求 `verification_token`，加密回调会校验签名并解密事件。

可选能力（默认值保持保守）：

- `msg_gateway.feishu.render_mode`：`auto`（默认，检测到常见 Markdown 时转飞书 post）、`post` 或 `text`。
- `msg_gateway.feishu.media_enabled`：默认 `false`；设为 `true` 后才下载允许类型的入站图片/文件，并发送本地生成的图片/文件。
- `msg_gateway.feishu.max_media_bytes`：媒体下载大小上限，默认 20 MiB，最大按飞书资源接口限制为 100 MiB；出站图片和文件还分别受飞书上传接口限制。
- `msg_gateway.feishu.card_progress`：默认 `false`；设为 `true` 后启用 CardKit 流式进度。处理中可发送 `/stop` 取消当前任务。

例如，启用媒体并将回调监听在本机 6710 端口：

```bash
go run ./cmd/la config set msg_gateway.feishu.media_enabled true
go run ./cmd/la config set msg_gateway.feishu.max_media_bytes 20971520
go run ./cmd/la config set msg_gateway.feishu.verification_token your-verification-token
go run ./cmd/la config set msg_gateway.feishu.listen_addr 127.0.0.1:6710
go run ./cmd/la config set msg_gateway.feishu.path /feishu/events
```

回调监听需要能被飞书服务端访问；生产部署请通过 HTTPS 反向代理暴露回调地址。应用还需按启用能力开通消息收发、媒体和 CardKit 相关权限。最近活跃的会话目标会保存在 `${HOME}/.luckyagent/runtime/recent_chat_target.json`，供重启后的主动任务选择投递会话。

### Weixin

LuckyAgent 支持个人微信 iLink Bot API 入口。

关键字段：

- `msg_gateway.weixin.token`
- `msg_gateway.weixin.account_id`
- `msg_gateway.weixin.base_url`
- `msg_gateway.weixin.dm_policy`
- `msg_gateway.weixin.group_policy`

启动：

```bash
go run ./cmd/la msg-gateway start --platform weixin
```

登录辅助：

```bash
go run ./cmd/la msg-gateway weixin-login
```

## 8. RAG 知识库

索引目录：

```bash
go run ./cmd/la rag index ./docs
```

搜索：

```bash
go run ./cmd/la rag search "deployment"
```

RAG 可用于给 Agent 注入项目文档、个人笔记、运维手册和长期知识。

## 9. Docker 部署

开发环境：

```bash
docker compose up -d --build luckyagent
```

生产环境：

```bash
docker compose -f docker-compose.prod.yml up -d
```

启用 Telegram profile：

```bash
docker compose -f docker-compose.prod.yml --profile telegram up -d
```

启用 NapCat profile：

```bash
docker compose -f docker-compose.prod.yml --profile napcat up -d
```

容器部署时最重要的是确认：

- `HOME` 指向持久化目录，例如 `/var/lib/luckyagent`
- `config.json` 挂载到 `${HOME}/.luckyagent/config.json`
- `server.addr` 是否允许容器内外访问

## 10. 常用排障

配置没生效：

- 检查当前进程的 `HOME`
- 检查 `${HOME}/.luckyagent/config.json`
- 容器里确认挂载路径是否正确

消息网关连不上 API：

- 检查 `server.addr`
- 容器跨服务访问不要使用错误的 `127.0.0.1`
- 检查防火墙和端口映射

NapCat 连接失败：

- 确认 LuckyAgent 已启动 NapCat 网关
- 确认 NapCat URL 路径和端口一致
- 跨机器部署不要监听 `127.0.0.1`

模型调用失败：

- 检查 `provider`
- 检查 `api_key`
- 检查 `api_base`
- 检查 `model`
- 查看 `~/.luckyagent/logs`
