# 会话回顾

回合完成并保存后，Agent 使用当前默认 Provider 另发一次不带工具的模型请求，
生成一句用户语言的回顾，保留代码标识符。问询描述为「你问了…」，实际完成的
更改描述为「我们…」；计划、尝试和失败不能写成已完成。输出不含标签、列表
或第二句。没有有效输出时保留上一份。

输入由上一份回顾、最新用户请求和最近至多 64 条真实 user / assistant / tool 消息组成，
按最新优先保留约 12,000 字符，每条至多 2,000 字符；工具名称和状态一起提供。
不包含推理正文、system 消息、compact summary、记忆或 RAG。长正文使用会话
中现有预览，所以回顾是简短导航信息，不能作为完整执行证据。

后台最多同时运行两个回顾请求，同一会话的新请求合并为最新一次，每次超时
20 秒。生成不占用用户回合等待时间；关闭 Agent 最多等待 3 秒，再取消未完成
生成。快速退出的一次性 CLI 可能来不及保存新回顾，已有回顾仍保留。

runtime 将 `recap` / `recap_updated_at` 写入会话元数据及派生索引；写入前
检查来源版本，后续消息或会话删除使旧结果失效。回顾不改变标题、聊天历史或
会话更新时间，重启、空闲返回和重新打开都复用持久化文本。

HTTP 列表、搜索、单会话响应透出可选字段。Android 标题下显示最多两行，
重新进入或回到前台时刷新，并在输入框上方显示可收起的菱形卡片；中英日韩
标签跟随回顾语言。CLI `lh session list` 和 REPL `/sessions`、
`/session search`、`/session switch` 展示同一字段。

无需修改 `config.example.json`：未新增配置项。每次成功回合可能增加一次
简短模型调用及相应 Provider 费用；客户端没有额外生成调用。
